## 五、物理模型与数值方法

### 5.1 运动方程

双摆由两个广义坐标 θ₁、θ₂ 描述，其拉格朗日方程化简后为：

```text
θ₁'' = [ -g(2m₁+m₂)sinθ₁ - m₂g·sin(θ₁-2θ₂)
         - 2sin(θ₁-θ₂)·m₂·(ω₂²L₂ + ω₁²L₁cos(θ₁-θ₂)) ]
       / [ L₁(2m₁+m₂ - m₂cos(2θ₁-2θ₂)) ]  - b·ω₁

θ₂'' = [ 2sin(θ₁-θ₂)·( ω₁²L₁(m₁+m₂) + g(m₁+m₂)cosθ₁
                        + ω₂²L₂m₂cos(θ₁-θ₂) ) ]
       / [ L₂(2m₁+m₂ - m₂cos(2θ₁-2θ₂)) ]  - b·ω₂
```

其中 `b` 为阻尼系数。与单摆的 `θ'' = -(g/L)sinθ` 相比，双摆的两个方程**互相耦合**，
不存在解析解，必须数值求解 —— 这是本实验与第 05 周初版单摆最核心的区别。

### 5.2 数值积分

状态向量为四维 `[θ₁, ω₁, θ₂, ω₂]`，采用**定步长 RK4** 积分，`h = 0.002 s`。
RK4 每步需计算 4 个阶段的斜率（共 16 个分量），是本实验计算量的主要来源。

### 5.3 机械能

以悬挂点为零势能面（y 轴向上）：

```text
U = -m₁gL₁cosθ₁ - m₂g(L₁cosθ₁ + L₂cosθ₂)
K = ½m₁L₁²ω₁² + ½m₂(L₁²ω₁² + L₂²ω₂² + 2L₁L₂ω₁ω₂cos(θ₁-θ₂))
```

面板显示的 `E/E₀` 为**平移到最低点再归一**的比值：

```text
E/E₀ = (E - U_bottom) / (E₀ - U_bottom)      U_bottom = -(m₁+m₂)gL₁ - m₂gL₂
```

这样处理后比值恒在 `[0, 1]` 区间：无阻尼时稳定在 `1.00000`（证明积分器无能量泄漏），
有阻尼时单调下降至 `0`。**若直接使用裸 `E/E₀`，会因 E₀ 偏小而使比值穿过零点变成负数**
（实测可达 `-0.83`），详见第八节问题记录。

## 六、数值验证结果

以下数据由**独立的 Python 3.12 验证脚本**复现同一套方程与步长后实测得出，
参数为默认值 `L₁=L₂=200, m₁=m₂=1, g=9.8, θ₁(0)=θ₂(0)=120°, ω=0`。

| 检验项 | 实测结果 | 判定 |
| :--- | :--- | :--- |
| 能量守恒（400 s / 20 万步） | 最大相对漂移 **3.065e-12** | 积分器稳定，无能量泄漏 |
| 步长充分性（h=0.002 vs h=0.0005，t=20 s） | 状态最大偏差 **1.726e-14** | 步长足够，无需减小 |
| 混沌性（初值扰动 1e-9） | 210 s 放大至 O(1)，**λ ≈ 0.0987 /s** | λ > 0，系统确为混沌 |
| 阻尼耗散（b=0.010，100 s） | 机械能单调递减 | 阻尼项符号正确 |
| 越顶行为（500 s） | θ₁ 越顶 **2 次**（最大 501.4°）；θ₂ 越顶 **3 次**（最大 **1234.5°**） | 下摆球可连续翻滚 3 圈以上 |

**结论**：RK4 在本实验的步长下精度充裕，能量漂移比物理信号小 12 个数量级；
李雅普诺夫指数为正，双摆的混沌特性得到数值证实。

### 6.1 初始角为何取 120° 而非 45°

按能量预算计算，初始角 45° 时系统能量仅占"从最低点到两摆竖直向上"全量程的 **14.6%**，
运动过于温和，难以体现混沌；取 120° 时占比为 **75.0%**，可在保持有界摆动的同时展现典型混沌翻滚。

> 如需改回 45°：修改 `index.html` 中 `var THETA0 = 120 * Math.PI / 180;` 为 `45 * Math.PI / 180;` 即可。

## 七、交互操作说明

| 操作 | 效果 |
| :--- | :--- |
| 拖拽摆球 1（上，青色） | 改变 θ₁，摆球 2 刚性跟随 |
| 拖拽摆球 2（下，蓝色） | 以摆球 1 为基点改变 θ₂ |
| 释放鼠标 | 角速度归零，从当前位置作为新的初始条件起摆 |
| 按钮「暂停 / 继续」或 **空格** | 暂停 / 恢复动画 |
| 按钮「重置摆动」或 **R** | 两摆角精准复位至初始角，角速度归零 |
| 滑块：摆长 L₁ / L₂ | 80 ~ 280 px，实时改变动力学系数 |
| 滑块：重力 g | 1 ~ 25 |
| 滑块：阻尼 b | 0.000 ~ 0.010 |
| 滑块：时间倍率 | 1× ~ 60×，**仅影响播放速度，不改变物理结果** |

> **时间倍率的由来**：本实验沿用"摆长以 px 计、g 取 9.8"的参数约定，存在单位量纲混用，
> 导致真实周期长达数十秒，屏幕上几乎看不出运动。时间倍率只做播放加速，面板上的
> θ、ω、E/E₀ 等读数均为真实物理值，不受倍率影响。

## 八、问题与修正记录

| 序号 | 问题 | 原因 | 处理 |
| :---: | :--- | :--- | :--- |
| 1 | 暂停时拖尾渐变被压扁 | 静止帧持续向轨迹数组压入重复坐标点 | 加入 1.5 px 位移阈值过滤重复点 |
| 2 | 摆长调大后下摆球被底部面板遮挡 | 两段摆长之和最大 560 px，超出可视区 | 引入**仅作用于渲染**的自动缩放，物理计算仍用真实摆长，缩放系数在面板公示 |
| 3 | `E/E₀` 在阻尼模式下显示为负数（实测 −0.83） | 势能零点在悬挂点，最低点势能为负；E₀ 偏小时比值会穿零 | 将能量零点平移至最低点后再归一，修正后实测比值恒在 `[0, 1]` |
| 4 | 双摆无确定周期，但仍显示 T₀ / 实测 T | 周期读数是单摆的零交叉检测逻辑，对混沌系统无意义 | 移除该两项，改为显示 θ₁、ω₁、θ₂、ω₂ 与两摆夹角 \|θ₁−θ₂\| |

## 十、数据与结论

1. 双摆的运动方程因两自由度耦合而**无解析解**，必须依赖数值方法求解；
2. 定步长 RK4 在 `h = 0.002 s` 下的能量相对漂移仅 `3.065e-12`，精度远优于本实验所需；
3. 初始条件相差 `1e-9` 的两条轨道在约 210 s 后完全分离，**李雅普诺夫指数为正**，
   从数值上证实了双摆的混沌本质 —— 这是"确定性系统亦可不可长期预测"的直接证据；
4. 双摆的混沌运动**不破坏能量守恒**（无阻尼时 `E/E₀` 恒为 1.00000），
   说明混沌源于方程的非线性，而非数值误差。
