1. 建立**含二次空气阻力**的二维抛体运动微分方程，理解其相对真空抛体的差异；

## 五、物理模型与数值方法

### 5.1 运动方程

状态向量为四维 `[x, y, vx, vy]`：

```text
x'  = vx                y'  = vy
vx' = -k·|v|·vx         vy' = -g - k·|v|·vy        |v| = √(vx² + vy²)
```

其中 `k` 为二次阻力系数（单位 1/m），`g = 9.8 m/s²`。

> **量纲说明**：本实验统一使用**真实物理单位**（长度 m、速度 m/s、角度 °）。
> 像素仅用于渲染换算，**不参与任何物理计算**。这修正了第 05 周把 `L` 取 px 而 `g` 取 9.8 m/s²
> 所导致的量纲混用问题 —— 那次不得不引入"时间倍率"来做视觉补偿，本实验不需要。

### 5.2 数值积分

定步长 RK4，`h = 0.0005 s`。每步计算 4 个阶段的斜率（共 16 个分量）。

### 5.3 真空解析解（k = 0）

`k = 0` 时方程退化为经典抛体运动，存在闭式解，用作积分器的**校验基准**：

```text
射程      R   = v₀²·sin(2θ) / g
最大高度  H   = (v₀·sinθ)² / (2g)
飞行时间  T   = 2·v₀·sinθ / g
靶面高度  y(D) = D·tanθ - g·D² / (2·v₀²·cos²θ)
```

### 5.4 靶面与环数

竖直靶板位于 `x = D`，靶心高度 `10 m`，5 个同心环、环间距 `1 m`（外半径 `5 m`）。
弹丸穿越靶面时记偏差 `dev = y(D) - 10`，环数为：

```text
环数 = 11 - ceil(|dev| / 1)，当 |dev| ≤ 5 m；否则脱靶
```

### 5.5 散布模型

每次发射对参数施加高斯扰动（Box-Muller 方法），模拟装药量波动与发射抖动：

```text
v₀' = v₀ · (1 + ξ₁ · σᵥ / 100)        ξ ~ N(0, 1)
θ'  = θ + ξ₂ · σθ · π / 180
```

默认 `σᵥ = 1.0 %`、`σθ = 0.3°`。

## 六、数值验证结果

以下数据由**独立的 Python 3.12 验证脚本**复现同一套方程、步长与事件判定后实测得出。

### 6.1 积分器精度：RK4 对照真空解析解

参数 `v₀ = 30 m/s`，`θ = 45°`，`k = 0`，`h = 0.0005 s`：

| 物理量 | 解析解 | RK4 数值解 | 相对误差 |
| :--- | ---: | ---: | ---: |
| 射程 | 91.8367346939 m | 91.8367343906 m | **3.302e-09** |
| 最大高度 | 22.9591836735 m | 22.9591836114 m | **2.706e-09** |
| 飞行时间 | 4.3292251909 s | 4.3292251766 s | **3.302e-09** |

三项误差同处 `1e-09` 量级，验证了积分器与事件插值逻辑的正确性。

### 6.2 步长充分性（含空气阻力）

`k = 0.010`，`v₀ = 30 m/s`，`θ = 45°`：

| 步长 | 最大高度 | 落点 | 飞行时间 |
| :--- | ---: | ---: | ---: |
| h = 0.0005 s | 17.125277705 m | 55.818236415 m | 3.727000 s |
| h = 0.0000625 s | 17.125277734 m | 55.818236422 m | 3.726563 s |
| **偏差** | **2.910e-08 m** | **7.179e-09 m** | — |

步长缩小 8 倍后结果变化仅 `3e-08 m` 量级，说明 `h = 0.0005 s` 已远超精度需求。

### 6.3 空气阻力对射程的削减

`v₀ = 30 m/s`，`θ = 45°`（真空射程基准 91.8367 m）：

| 阻力系数 k (1/m) | 实际射程 | 射程削减 | 最大高度 |
| :---: | ---: | ---: | ---: |
| 0.0000 | 91.8367 m | 0.00 % | 22.9592 m |
| 0.0020 | 80.5620 m | **12.28 %** | 21.3616 m |
| 0.0050 | 68.6487 m | **25.25 %** | 19.4623 m |
| 0.0100 | 55.8182 m | **39.22 %** | 17.1253 m |
| 0.0200 | 41.5752 m | **54.73 %** | 14.0884 m |

**结论**：二次阻力对射程的削减是**非线性**的 —— `k` 从 0 增至 0.005（+0.005）削减 25.25%，
再从 0.005 增至 0.010（同为 +0.005）却只再削减 13.97%，削减速率随 `k` 增大而**递减**。

### 6.4 弹着散布：解析预测 vs 蒙特卡洛

默认参数 `v₀ = 30 m/s`、`θ = 45°`、`D = 80 m`、`σᵥ = 1.0 %`、`σθ = 0.3°`。

先用误差传播公式预测靶面高度的标准差：

```text
∂y/∂v₀ = g·D² / (v₀³·cos²θ)          = 4.6459 m/(m/s)
∂y/∂θ  = D·sec²θ·[1 - (gD/v₀²)·tanθ] = 20.6222 m/rad
σ_y    = √( (∂y/∂v₀·σ_v₀)² + (∂y/∂θ·σθ)² )
```

| 误差来源 | 单项贡献 |
| :--- | ---: |
| 初速波动 σᵥ = 1 % | 1.3938 m |
| 角度波动 σθ = 0.3° | 0.1080 m |
| **理论合成 σ_y** | **1.3980 m** |
| **蒙特卡洛实测 σ_y**（n = 4000） | **1.4035 m** |
| **相对偏差** | **0.40 %** |

**这组对比是本实验最有价值的结果**：解析误差传播预测与 4000 次蒙特卡洛模拟仅差 0.40%，
并且显示出**初速波动贡献了 99.4% 的散布**（1.3938 m vs 0.1080 m）—— 也就是说，
在角度控制精度已足够的前提下，**射弹散布主要由初速一致性决定**。

4000 发模拟的环数分布：

| 环数 | 10 环 | 9 环 | 8 环 | 7 环 | 6 环 | 脱靶 |
| :---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 发数 | 2026 | 1322 | 515 | 119 | 18 | 0 |
| 占比 | 50.7 % | 33.1 % | 12.9 % | 3.0 % | 0.45 % | 0 % |

### 6.5 随机数发生器质量

Box-Muller 变换，300000 个样本：样本均值 **−0.00077**（理论 0），样本标准差 **1.00019**（理论 1），
分布质量满足蒙特卡洛实验要求。

### 6.6 环数判定边界

| dev (m) | −5.001 | −5.000 | −4.000 | −2.000 | −1.000 | 0.000 | +1.000 | +5.000 | +5.001 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 环数 | 0 | 6 | 7 | 9 | **10** | **10** | **10** | 6 | 0 |

边界取值符合"环间距 1 m、`|dev| ≤ 1 m` 为 10 环"的定义，且 `|dev| = 5 m` 恰好为 6 环（含端点）。

## 八、问题与修正记录

本实验在开发过程中发现并修正了 **3 处缺陷**，其中前两处是真实的运行时缺陷。

| 序号 | 问题 | 原因 | 处理与验证 |
| :---: | :--- | :--- | :--- |
| 1 | **发射角恰为 0° 时弹丸永不落地** | 落地判定条件写作 `py > 0`，而 θ=0 时首步 `py` 恰好等于 0，条件永不成立，弹丸会一直下坠到 90 s 超时 | 改为 `py >= 0`。回归测试：修复前耗时 **90.0 s 且判定为 timeout**，修复后 **0.0005 s 判定为 land、落点 0.0000 m** |
| 2 | **越过靶面后实际射程丢失** | 一旦穿过靶面就置 `shotDone = true`，导致随后真正落地时被提前返回，射程读数错误地显示为靶距 | 拆分为 `onBoard` / `onGround` 两个独立事件记录 + `finalizeShot` 统一结算，每次射击恰好产生一条统计记录 |
| 3 | 飞行时间被量化到步长边界 | 事件时刻直接取 `flightT`（步长整数倍），未做步内插值 | 用事件在步内的插值比例回算时刻。误差由 **6.348e-05** 降至 **3.302e-09** |

## 十、数据与结论

1. 二次空气阻力下的弹道**不存在解析解**，必须数值求解；而其 `k = 0` 的极限情形存在闭式解，
   恰好构成对积分器的**严格校验基准**。本实验 RK4 三项物理量的相对误差均达 `1e-09` 量级。
2. 空气阻力对射程的削减是**非线性且边际递减**的：`k` 每增加 0.005，前半段削减 25.25%，
   后半段仅再削减 13.97%。
3. 弹着散布的主要来源是**初速一致性**而非角度精度 —— 初速 1% 的波动贡献 `1.3938 m` 标准差，
   是角度 0.3° 波动贡献（`0.1080 m`）的 **12.9 倍**。
4. 误差传播的**解析预测**与 4000 次**蒙特卡洛模拟**仅相差 0.40%，
   说明在小扰动下系统响应近似线性，线性化误差传播模型在此参数范围内完全适用。
5. 本实验修正的 3 处缺陷表明：**数值方法本身的精度（`1e-09`）与工程实现的事件判定逻辑
   （如 θ=0 边界、状态标志时序）是两个独立的误差来源**，前者可靠不代表后者正确 ——
   必须用回归测试覆盖边界条件。
